# MAX Mini App — тесты из Markdown

## Структура

miniapp/
- index.html
- app.js
- style.css
- tests/
  - test-001.md

## Запуск

Для локальной проверки нужен HTTP-сервер, потому что браузер блокирует fetch() локальных Markdown-файлов.

Например:

python -m http.server 8000

После этого открыть:

http://localhost:8000/

## Выбор конкретного теста

Можно открыть:

http://localhost:8000/?test=test-001.md

Позже этот параметр можно заменить на deep link MAX.

## Важно

Парсер рассчитан на текущий формат ваших Markdown-файлов:
- # Заголовок
- Хук:
- ## Вопросы
- 1. Вопрос
- - A. Ответ
- - B. Ответ
- - C. Ответ
- - D. Ответ
- ## Результаты
- A — Заголовок результата
